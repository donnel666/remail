# 抽奖评分

`fixed-tier-v3` 在开奖时，按所有历史记录计算参与者评分：

```text
评分 = max(0,
  1000
  - 幸运奖次数 × 500
  - 普通奖次数 × 100
  + 安慰奖次数 × 50
  + (充值所得积分 + 排行榜及邀请所得积分 - 免费所得积分) / 100
  - 订单售后工单数 × 10
)
```

积分除以 100 保留小数；所有加减完成后再将负数限制为 0。分数从高到低排列，同分随机排列，然后依次分配固定数量的幸运奖、普通奖和其余安慰奖。评分不修改钱包余额。

| 统计项 | 范围 |
| --- | --- |
| 历史奖项次数 | 已完成抽奖中的幸运奖、普通奖、安慰奖记录 |
| 充值所得积分 | 已入账在线充值、卡密兑换；按得到的积分计算 |
| 排行榜及邀请所得积分 | 已入账排行榜奖励、邀请奖励、邀请返利转入 |
| 免费所得积分 | 消费钱包的其他赠送入账，包括抽奖、签到、注册赠送及管理员赠送 |
| 订单售后工单数 | 每个 `ticket_type=order` 工单计一次，不区分待处理、处理中、已退款或关闭；同一订单的不同工单分别计数 |

积分统计排除已冲正流水、退款到账、供应商收入及供应商余额转入。普通咨询、供应商申请和提现等 `general` 工单不计入扣分。邀请返利在转入消费钱包后计分，未到账奖励不计入。

例如：充值所得 1,000 积分加 10 分；排行榜或邀请所得 1,000 积分加 10 分；抽奖所得 1,000 积分扣 10 分。抽奖所得的金额扣分与原有奖项次数调整同时生效。

统计通过 Billing、Aftersale 的批量查询接口读取，并共享开奖事务。开奖事务使用 `READ COMMITTED`，在取得参与用户锁后读取最新已提交的中奖次数和积分，避免并行活动漏计前一场刚发放的奖励。查询失败会保留活动等待重试，不使用缺失统计开奖。已有发奖结果继续幂等重放，不重新计算；v1/v2 活动保留原有算法。
